# 11. Хранение системного промта

Date: 2026-09-19

## Status

Accepted

## Context

На этапе MVP системный промт единственный и не содержит подстановок. Требуется определить место его хранения.

## Decision

На этапе MVP системный промт будет храниться в ресурсах системы.

## Alternatives

Хранить в корпоративном Consul.

## Consequences

Иногда системный промт бывает нужно поменять, в связи с этим разумно было бы на поздних этапах (после разрабатываемого MVP) перенести его во внешнее хранилище с разделением прав доступа. Поэтому архитекторы решили завести техдолг по переносу системного промта в Consul.
