# 1. Записываем архитектурные решения

Date: 2026-09-09

## Status

Accepted

## Context

По требованию к дипломному проекту архитектурные решения будут записываться

## Decision

Записываем архитектурные решения, как [описано Майклом Найгардом в](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions).

## Alternatives

Вариант "не записывать архитектурные решения" скорее всего приведёт к тому, что в дипломе не будет указано название дипломного проекта.

## Consequences

См. вышеупомянутую статью. Для создания ADR используется инструмент Нэта Прайса [adr-tools](https://github.com/npryce/adr-tools).
