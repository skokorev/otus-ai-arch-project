# 7. Исполнение требований законов

Date: 2026-09-12

## Status

Accepted

## Context

В соответствии с п.5 [НФТ ТЗ](../../docs/tz.md) на MVP требуется выбрать способ подбора и рассылки статей без использования персональных данных (далее ПДн).

## Decision

В систему будут поступать только адреса электронной почты получателей рассылки. Адреса электронной почты без дополнительных признаков не являются достаточными данными, чтобы их рассматрировать как ПДн, согласно результату аудита системы службой информационной безопасности Яхундекс. Более того, даже они не будут попадать на вход модели, осуществляющей выбор статей.

## Alternatives

Для выбора статьи и в дальнейшем можно ограничиться списком интересов (подробный список может располагаться, например, в пользовательском промте), без передачи ПДн на вход модели. Таким образом, данные не смогут утечь вовне.

## Consequences

При дальнейшей модификации системы и ввода в неё пользовательского списка интересов необходимо будет скорректировать системый промт (убрать оттуда упоминание локального поиска, настроить пользовательский промт и guardrails для предотвращения отравления ввода или tool получения пользовательских предпочтений (но guardrails всё равно остаются)).

В ходе развития системы требование непопадания под 152-ФЗ может быть снято для более персонализированного вывода (например, добавления обращения в тексте письма), но для генерации выбора ПДн всё равно не нужны и таким образом, под 152-ФЗ попадает только детерминированная часть системы, что будет митигировано применением crypto shredding для "права на забвение" и автоматическим удалением всех данных о пользователе при отписке от всех рассылок (с учётом периода максимального хранения ПДн).
