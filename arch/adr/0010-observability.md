# 10. Наблюдаемость

Date: 2026-09-18

## Status

Accepted

## Context

Требуется выбрать стек наблюдаемости для системы

## Decision

Будет использоваться стек, принятый в Яхундекс: grafana, prometheus
В качестве коллектора логов будет использоваться Loki
Langfuse 3 в MVP использоваться не будет, вместо этого при необходимости соответствющие сигналы можно вы усечённом виде с малой дискретизацией выводить в обычные сервисы наблюдаемости.

## Alternatives

Вместо Opensearch можно, конечно, использовать Loki, но он не имеет хороших встроенных средств поиска по логам (таких как Lucene, а это как раз то, в чём в Яхундекс особенно хорошо разбираются). OpenSearch, Grafana, Premetheus имеются в Яхундекс и не требуют альтернатив.

Langfuse 3 и 4 требует для On-premise развёртывания Clickhouse, которого нет в технорадаре Яхундекс, Langfuse 2 на PostgreSQL архитекторы решили не использовать по причине окончания его поддержки. Использование cloud-сервисов наблюдаемости нежелательно, если они не встроены в одобренный список, составляемый службой информационной безопасности Яхундекс.

## Consequences

Архитекторы решили использовать для MVP Loki из-за поддержки его "из коробки" в spring boot starter, но записали в техдолг, что в дальнейшем необходимо:
1. Добавить в развёртывание OpenTelemetry agent
2. Перевести разработку на OpenSearch
