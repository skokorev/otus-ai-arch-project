# 6. Пригодность информации для выборки

Date: 2026-09-10

## Status

Accepted

## Context

Требуется определить минимальную достаточность информации для выбора статей для MVP

## Decision

Для выбора будет использоваться аннотация статьи (abstract)

## Alternatives

В ходе первоначальной оценки (см. [ADR 2](0002-poc.md)) использовались аннотации статей из ArXiv и были признаны достаточными. Можно использовать полный текст статей, для этого требуется получать его (что повлечёт за собой учёт ROBOTS.TXT с ArXiv для работы сборщика статей (микросервис crawler) и необходимость в сохранении этого текста для дальнейшей обработки). Далее последовательность такова: разбить на чанки, вычислить по каждому из чанков вектор (добавляется либо эмбеддинг, сохраняемый в БД, либо полноценное векторное хранилище), по векторам строится поисковый индекс (максимально приближенный к графу Делоне для обеспечения скорости поиска O(log(N))) и по векторизованному запросу (+ ещё один такой же эмбеддинг на запрос или встроенный в векторное хранилище), по индексу осуществляется поиск чанков, по чанкам подбираются id статей. Реализация всего этого потребует дополнительной инфраструктуры, которой на этапе MVP у архитекторов Яхундекс нет (есть только тестовый стенд из одного сервера, выделенный для проведения MVP).

## Consequences

Отбор статей на этапе MVP производится более грубым образом, нежели можно было бы представить себе в перспективе. Митигируется на первоначальном этапе тем, что аннотации научных статей на ArXiv составляются достаточно добросовестно и имеют достаточно информации для того, чтобы произвести выбор.
