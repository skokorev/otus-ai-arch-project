# 16. Тестирование

Date: 2026-09-22

## Status

Accepted

## Context

Требуется принять решение по способу тестирования на этапе MVP.

## Decision

Будет производиться ручное тестирование продукта. Для этого будет создан специальный тестовый контроллер сервиса crawler, недоступный извне контейнера (не будет опубликован HTTP-порт). Автоматические тесты для сервисов будут созданы позже.

## Alternatives

- Написать тесты сразу, это самый предпочтительный путь, но он не выбран из-за того, что это затянет сроки разработки.
- Не писать тесты вообще, это приведёт к ненаблюдаемым ошибкам, выявляющимся на этапе эксплуатации, а не во время разработки.

## Consequences

Архитекторы решили:
- Полностью покрыть все сервисы автоматическими unit-тестами
- Добавить проверку Avro-схем для всех сообщений в Kafka, после этого создать автоматические интеграционные тесты на контракты (http + kafka)
- Создать end-2-end тесты для всей системы
Все эти задачи были записаны в техдолг и будут выполнены после релиза MVP.
