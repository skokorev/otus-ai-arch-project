# 2. Возможность реализации

Date: 2026-09-10

## Status

Accepted

## Context

Архитекторы Яхундекс хотят оценить реализуемость своего проекта по отбору наиболее интересных статей из выборки за последнюю неделю. Для этого они в качестве POC составляют промт, который вручную наполняется параметрами статей из ArXiv (id, title) и содержит требование отранжировать статьи по шкале от 0 до 10 отобрать 3 наиболее интересных с точки зрения сотрудника организации, занимающейся локальным поиском. Промт запускается несколько раз с разным параметром температуры и с одинаковым параметром температуры в разное время. Результат вывода модели Qwen3.6-35B видится архитекторам приемлемым в рамках некоммерческой инициативы внутри Яхундекс. 

## Decision

Реализуем проект "Советник/помощник архитектора по подбору статей из ArXiv"

## Alternatives

Альтернативный вариант "не реализуем некоммерческий проект" приведёт к экономии рабочего времени в краткосрочной перспективе (архитекторам Яхундекс разрешено заниматься деятельностью по саморазвитию в течение 6 часов в неделю в рабочее время), но задача подбора наиболее интересных к ознакомлению статей из ArXiv будет по-прежнему выполняться вручную, что увеличит время на подбор действительно полезных статей. Более того, выборка из трёх статей в неделю по одной тематике поможет архитекторам Яхундекс выработать лучшее усвоение прочитанного материала за счёт совместного их (статей) обсуждения.

## Consequences

Один из архитекторов Яхундекс выделяет своё время на саморазвитие в течение 2 недель для создания MVP проекта "Советник/помощник архитектора по подбору статей из ArXiv". Остальные архитекторы Яхундекс помогают ему с принятием архитектурных решений.
Риски: реализация проекта не даст желаемого результата, способ митигации - принятие риска, так как проект некоммерческий - потеряно будет только не более 12 часов одного из архитекторов и ещё примерно 4 часа на всех остальных.
